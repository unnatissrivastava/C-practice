# C Practice

A collection of C programming practice programs created while learning the fundamentals of Programming in C.

## Topics Covered
- Addition of rows in a 2D array
- Armstrong number
- Ascending and descending order
- Factorial
- Finding an element in a 2D array
- Finding even and odd elements in a 2D array
- Harshad number
- Maximum and second maximum element in an array
- Number of digits
- Number of 5s in a number
- Product of digits
- Sum of digits
- Sum of first and last digit
- Array traversal

## Language

- C
## Purpose

This repository is maintained as part of my journey to strengthen my C programming fundamentals, problem-solving skills, and understanding of arrays, loops, conditions, and number-based problems.
